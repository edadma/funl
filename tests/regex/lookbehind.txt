# Lookbehinds PCRE2 is no oracle for, with the spans worked out by hand: pattern, subject, the first
# match's spans, and why. A lookbehind here is matched backward from the position (docs/design/vm.md,
# "Forward and reverse"), so it may be any pattern at all.
#
# PCRE2 refuses these outright: its lookbehind must have a bounded length.
(?<=a+)b	aaab	(3,4)	unbounded repetition
(?<=a+)b	b	NOMATCH	unbounded repetition, and nothing before the b
(?<=(a+))b	xaaab	(4,5)(1,4)	unbounded; greedy backward, the group takes every a
(?<=(a+?))b	xaaab	(4,5)(3,4)	unbounded; lazy backward, the group takes the one a next to the b
(?<=^\w*)b	aab	(2,3)	unbounded, anchored at the start
(?<=^\w*)b	a b	NOMATCH	unbounded, and the space stops the word before the start
(?<=(a|bc)+)d	abcad	(4,5)(0,1)	alternatives of different lengths, repeated without bound; a group keeps its last turn, which backward is the leftmost
(?<=^(?:ab|c)*)x	ababcx	(5,6)	alternatives of different lengths, repeated without bound
(?<=^(?:ab|c)*)x	abbx	NOMATCH	alternatives of different lengths, repeated without bound; no way to read abb back to the start
(?<=\d+(?:\.\d+)?)%	rate 12.5%	(9,10)	unbounded, with an optional part of its own
(?<=[^a]+)a	ññña	(3,4)	unbounded, stepping back over two-byte characters
(?<=(\w+?)(\w+))!	abc!	(3,4)(0,1)(1,3)	unbounded; the greedy group is matched first and gives back one character so the lazy one can have it
(?<=\1 (\w+) )z	ab ab z	(6,7)(3,5)	unbounded; backward, the group on the right is matched before the backreference on its left
(?<=a++a)b	aab	(2,3)	unbounded and possessive; backward, the last a is taken before the run
(?<=(?<=a+)b+)c	aabbc	(4,5)	nested, both unbounded
(?<=(?<=a+)b+)c	bbc	NOMATCH	nested, both unbounded; no a before the b's
(?<=(?<!b)a+)c	baac	(3,4)	unbounded with a nested negative lookbehind, which fails at the whole run and holds after the run gives one a back
(?<=(?<!b)(a+))c	baac	(3,4)(2,3)	the same, the group showing the run gave one a back
(?<!a.*)b	xb	(1,2)	unbounded, negative
(?<!a.*)b	axb	NOMATCH	unbounded, negative
#
# PCRE2 accepts these and reads them another way: it tries the starts a lookbehind could have, the
# farthest first, and matches forward from each. Whether a plain lookbehind holds is the same either
# way; which alternative or how many repetitions a group inside it takes, which turn of a repeated
# group it keeps, a backreference inside it to a group inside it, and an atomic group inside it are
# not.
(?<=(a|aa))b	aab	(2,3)(1,2)	differs: backward the first alternative wins; PCRE2, starting as far back as it can, takes aa
(?<=(a{1,2}?))b	aab	(2,3)(1,2)	differs: lazy backward takes one a; PCRE2, starting as far back as it can, takes two
(?<=(a?)(a??))b	aab	(2,3)(1,2)(2,2)	differs: backward the lazy group is matched first and takes nothing; PCRE2 gives each group an a
(?<=(a?)(a?))b	ab	(1,2)(0,0)(0,1)	differs: backward the second group is matched first and takes the a; PCRE2 gives it to the first
(?<=(ab){2})c	ababc	(4,5)(0,2)	differs, though the length is fixed: a group keeps its last turn, which backward is the leftmost; PCRE2 keeps (2,4)
(?<=(\w)\1)x	aax	NOMATCH	differs: backward the backreference is reached before its group, which has captured nothing; PCRE2 answers (2,3)(0,1)
(?<=\1(\w))x	aax	(2,3)(1,2)	differs: backward the group is matched first, so the backreference on its left sees it; PCRE2 finds no match
(?<=(?>a|ab)b)c	abbc	(3,4)	differs: backward the atomic group is entered from its right end, where only ab fits; PCRE2 commits to a and finds no match
(?<=(?>a{0,2})a)b	aab	(2,3)	differs: backward the a outside the atomic group is taken first; PCRE2's atomic run takes both a's and finds no match
